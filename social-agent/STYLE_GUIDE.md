# Style guide

Edit this file to change how every draft sounds. The agent reads it on each run.

- Voice: clear, friendly, direct. Short sentences.
- Say what happened and why it matters in one line.
- No hype words ("game-changing", "revolutionary").
- Never invent facts, numbers, or quotes. Use only what the headline supports.
- Do not mention that the post was written by AI.
- Avoid politics, medical or financial advice, and anything about private individuals.
